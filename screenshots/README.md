# Screenshot Checklist

Add screenshots only after checking that they do not expose personal information, real passwords, product keys, email addresses, public IP addresses, or other sensitive data.

## High-Priority Screenshots

- Server Manager showing AD DS and DNS installed on `DC01`
- Active Directory Users and Computers showing the lab organizational-unit structure
- Test users and security groups
- A test user’s group-membership configuration
- Account disabled/enabled state during a support scenario
- Account-lockout and unlock workflow
- Group Policy Management showing the five-attempt lockout threshold
- Windows 11 system page showing successful domain membership, after verification
- Successful test domain-user sign-in, after verification
- Command output demonstrating DNS and domain-controller connectivity, after verification

## Screens Not Worth Adding

- Routine installation progress bars
- Generic Windows desktop screens
- Repeated views of the same configuration
- Screens containing passwords or personal information
- Any result that has not been fully tested
