# Security and Privacy Notes

This repository documents a private training lab. Before publishing screenshots or configuration exports:

- Remove or blur passwords, recovery keys, product keys, and tokens.
- Remove personal email addresses and real names not created solely for the lab.
- Do not publish public IP addresses or router configuration.
- Use test accounts and fictional data only.
- Review screenshots for browser tabs, notifications, and background windows.
- Do not upload virtual-machine images, Windows installation media, or licensed software.
